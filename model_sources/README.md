# Authored 3D models

`blender/` contains one Python source file for each of the nine spacecraft.
`lib.py` supplies geometry primitives and `common.py` supplies materials,
optimization and glTF export. The Python files are the editable models; the
generated GLBs are ignored build artifacts.

From the repository root:

```sh
model_sources/blender/build.sh             # all spacecraft → web/assets/*.glb
model_sources/blender/build.sh shuttle lm  # selected spacecraft
tools/sync_assets.sh                       # copy GLBs → assets/craft/ for Godot
```

The Godot game and archived web build both have procedural spacecraft
fallbacks when the GLBs are absent. Launch complexes are still generated by
`sim/flight/launchsite.gd` in Godot (and `web/sim/flight/launchsite.js` in the
web reference); they are not Blender assets yet.
